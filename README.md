# 🚀 AI Multi-Tenant E-Commerce Platform

A modern multi-tenant SaaS e-commerce platform powered by AI.

Built with:
- Laravel API
- React + TypeScript
- Tailwind CSS
- OpenAI API
- Multi-Tenant Architecture

---

# 🌟 Overview

This project is not just a traditional e-commerce store.

It is a scalable AI-powered SaaS platform designed to help merchants:
- manage stores
- improve sales
- automate workflows
- personalize customer experience using AI

# 🏗 Architecture

Frontend and backend are fully separated.

```text
React Frontend
      ↓
Laravel REST API
      ↓
MySQL Database
```

The platform follows scalable SaaS architecture principles.

# 🚀 Getting Started

## Backend Setup

```bash
cd ecommerce-api
composer install
php artisan serve
```

---

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
